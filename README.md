# Kamal Majumder executive portfolio

Open index.html for the executive homepage and projects.html for the filterable portfolio. Twelve individual case study pages are in projects/. The homepage includes an expandable career timeline, six leadership dimensions, DecisionAI prototype screenshots, and a downloadable executive resume. The homepage and project gallery share the theme in assets/executive.css.

## Deployment

Extract the ZIP. Place its contents in the directory your GitHub Pages site already publishes from, keeping index.html, projects.html, projects/, and assets/ in their relative locations. For Netlify, use the same directory as the publish directory. No build command is required.

## Editing

Edit homepage content in index.html and gallery content in projects.html. The existing case study URLs and files are retained. For the homepage and gallery theme, edit assets/executive.css. Gallery filtering uses assets/portfolio.js. Optional scroll animation uses assets/executive.js. The resume is Kamal-Majumder-Executive-Resume.pdf.

The separate single-file executive brief remains available outside this deployment folder.
